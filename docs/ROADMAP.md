# Roadmap

QiScreenwrite begins as a development source release. Work is prioritized around reliable writing and reversible exchange.

- Improve continuous page editing, print-layout fidelity, scene handling, revision tools and accessibility across desktop and iPhone.
- Test import/export against more real-world Fountain and FDX cases without claiming proprietary feature parity.
- Strengthen backup, restore and long-term preservation workflows, including physical-device recovery checks.
- Improve world continuity review, linked-world updates and explicit QiMovi/FilmStack transfers.
- Build the optional [CanIScreenwrite.com connection](CANISCREENWRITE-CONNECTION.md) through a verified staging API and reviewed submissions.
- Complete hosted scoring/profile services and authoritative purchase/job accounting before enabling token sales.
- Prepare reproducible installers, macOS distribution signing/notarization and an iPhone distribution path.

Real-time co-writing, locked production pages, direct phone-to-QiMovi networking, automatic cross-device synchronization and blockchain transactions are future capabilities. Dates and commercial terms are not established by this roadmap.

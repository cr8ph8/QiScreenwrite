# Public starter reference

This edition contains 17 independently written definitions and writing exercises, with links to Yale Film Analysis for further reading. Links are not fetched while browsing the offline catalog. No course decks, screenshots, film clips or article text are bundled. The exercises are suggestions, not scoring rules.

The root `sources` array is reserved for slide indexes and is empty in this edition. Each entry has its own public further-reading link. Desktop and iPhone use the same catalog bytes. After editing, run `node iphone/scripts/export-film-language.mjs`, then `npm run test:catalog` and `npm test`.

Contributions must be original or carry an explicit compatible redistribution license. Do not copy private teaching material into the public repository. This public starter edition is separate from any personally curated reference library.
